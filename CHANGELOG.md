# Changelog

## 0.1.0 — 2026-10-02

- English, Spanish and Russian with persisted runtime language switching, localized tray and messages.
- Native GTK4/libadwaita memory monitor with an asynchronous user-session agent.
- Persistent protected/high/normal priorities and optional soft memory limits.
- Verified cgroup attributes, ownership/ancestor checks and reversible policies.
- Native StatusNotifierItem tray with a live memory/protection summary.
- Agent protection from oomd and automatic crash recovery in a dedicated user unit.
- Ubuntu 26.04 / Linux 7.0+ runtime gate and amd64 Debian packaging.
- Local, atomic settings, bounded action history, read-only CLI diagnostics.
- Source-available no-resale license and dependency notices.
